## 프로젝트 한 줄 요약
국립한글박물관 소장자료총서 4종의 **글자 단위 바운딩박스 + 텍스트 데이터셋** 구축.  
판독문 정렬 기반 자동 라벨링 → S2 편집기로 사람 검수 → HRCNet 미세조정 → 성능 보드 비교.

## 현재 단계 (2026-09-19)
- gold-r02 스냅샷: 264자 (학습 234 / 평가 30), 편지 3·1·2·4
- 편집기(S2)와 성능 보드(S6·S7) 운영 중
- HRCNet 평가 대기 (gold-r02 패키지 준비 완료)
