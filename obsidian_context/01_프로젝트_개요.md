# 프로젝트 개요

## 목표
국립한글박물관 소장자료총서 4종 PDF에서 **글자 단위 바운딩박스(bbox) + 텍스트**를 구축한다.  
최종 산출물은 HRCNet(ResNet 백본 옛한글 사전학습 모델) 미세조정에 사용하는 학습 데이터셋이다.

## 핵심 설계 원칙
1. **제안과 정답 분리** — 기계 제안은 `proposed`로만 저장. 사람이 확정(`accepted`/`corrected`)한 것만 학습용 정답(gold).
2. **판독문 우선** — 텍스트 레이어 판독문이 있으면 OCR 값보다 판독문을 신뢰한다.  
   `engine=facsimile`의 `text` 필드는 판독문 정렬 결과, `rec` 필드는 테서랙트 원본.
3. **평가셋 불변** — `eval-v1`(편지 2, 30자)은 학습에 섞지 않는다. 변경 시 `eval-v2`로 새 이름.
4. **모든 실행에 계보** — 학습 스냅샷 이름과 내용 해시를 함께 기록한다.

## 세 도구의 역할
| 도구 | 역할 |
|---|---|
| **S2 편집기** | 기계 제안 검수·수정. 라운드마다 작업자가 사용. |
| **성능 보드** | 제안기 버전 비교, OCR 모델 등록·승격 판정, 데이터 계보 관리. |
| **HanOCR 파이프라인** | PDF → 글자 박스 제안 생성. 검수 정답을 반영해 라운드마다 보정. |
