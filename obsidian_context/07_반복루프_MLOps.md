# 반복 루프 (Human-in-the-loop MLOps)

## 흐름

```
PDF → S8 진단 → 파이프라인 제안 생성
        ↓
    S1 작업 큐 (신뢰도 낮은 순)
        ↓
    S2 편집기 (1차 검수·수정)
        ↓
    S4 2차 검수 승인
        ↓
    정답 스냅샷 저장 (gold-r0N)
        ↓
    HRCNet 학습 (GPU 환경)
        ↓
    evaluate_gold → 결과 JSON
        ↓
    성능 보드 등록 → 챔피언 판정
        ↓
    배포 → 새 제안 생성 (S1 큐 재정렬)
```
