## 모듈 역할

| 모듈 | 역할 | 주요 함수 |
|---|---|---|
| `cli.py` | CLI 진입점 | `run()`, `postprocess()` |
| `pipeline.py` | 쪽 단위 통합 | `process_page()`, `align_document()`, `finalize()` |
| `align.py` | NW 정렬 | `align(recs, gold)` → `(배정 index 리스트, 통계)` |
| `facsimile.py` | 영인 글자 검출 | `detect_chars()`, `binarize()` |
| `recognize.py` | 일괄 인식 | `recognize(ink, boxes, engine="tesseract")` |
| `figure_manual.py` | 지도 수동 주석 | `build(doc, pno, spec, outdir)` |
| `kimssi.py` | 필사 편지·상언·책 | `process_letter()`, `process_document()`, `process_book_page()` |
| `exemplar.py` | 정답 예시 은행 | `ExemplarBank`, `split_column_rag()` |
| `sections.py` | 판독문 문단 분석 | `find_sections()` |
| `textlayer.py` | 텍스트 레이어 추출 | `extract_chars()` |
| `normalize.py` | 옛한글 정규화 | `pua_to_jamo()`, `clusters()`, `nfc()` |
| `export.py` | 오버레이·CSV 출력 | `_overlay()` |
| `evaluate.py` | 텍스트 레이어 기준 평가 | `eval_page()` ← **현대 활자만** |
| `evaluate_gold.py` | 고정 평가셋 기준 평가 | `evaluate()` → 성능 보드 JSON |
| `labels.py` | 라벨 정의 | `LABELS` dict |

## 중요 데이터 흐름

```python
# run() 내부 순서
page = doc[pno]
tl = extract_chars(page)          # 텍스트 레이어 → typeset
has_text = len(tl) > 20

if not has_text:
    cs = ocr_chars(img, lang)     # Tesseract → typeset

# 영인 영역마다:
chars = detect_chars(img_bgr)     # 글자 성분 검출
recs = recognize(ink, boxes, engine="tesseract")  # 일괄 인식 → rec 필드
# align_document() 에서:

```

## 핵심 데이터 차이
- `text` 필드: 최종 값 (판독문 정렬 성공 시 판독문 글자, 실패 시 rec)
- `rec` 필드: 테서랙트 원래 인식값 (항상 보존)
- `bbox` (PDF pt): 영인 위치 (engine=facsimile) 또는 활자 위치 (engine=textlayer)
- `bbox_img`: 영인 이미지 파일 안 픽셀 좌표 (HRCNet 학습 시 이 값으로 잘라냄)
