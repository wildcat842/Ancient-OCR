# 데이터 모델

## chars.csv 컬럼

| 컬럼 | 설명 |
|---|---|
| page | PDF 쪽 번호 (1-based) |
| id | 글자 ID (p0019_c00012) |
| text | 최종 글자 값 (판독문 or OCR) |
| kind | hangul / hanja / punct / latin / digit / old_hangul |
| engine | textlayer / facsimile / tesseract |
| text_source | transcript-aligned / transcript-aligned-by-count / ocr / manual |
| rec | 테서랙트 원래 인식값 |
| conf | 신뢰도 (textlayer=1.0) |
| x0_pt … y1_pt | PDF 포인트 좌표 |
| ink_x0_pt … | 잉크 경계 조인 상자 (facsimile만) |
| x0_px … y1_px | render_dpi 기준 픽셀 좌표 |
