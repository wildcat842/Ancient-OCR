# 라벨 체계 (v0.7 기준)

자세한 내용: `LABELS.md` 참고

## 계층 구조
```
DOCUMENT / LETTER / BOOK_PAGE
  ├─ DOC_HEADER / DATE_LINE / SIGNATURE
  ├─ TEXT_COLUMN (행)
  └─ ENVELOPE_TEXT (봉투)

FIGURE (지도)
  ├─ FIGURE_PANEL (반구도 등 하위 그림)
  │   ├─ FIGURE_TITLE (제목 카르투시)
  │   └─ FIGURE_LABEL (표기)
  ├─ FIGURE_LEGEND → LEGEND_ITEM
  ├─ FIGURE_SCALE
  └─ GRATICULE_TEXT (경위도 눈금, 자동)

MARGIN_TEXT → MARGIN_TITLE / MARGIN_SECTION / MARGIN_FOLIO
```

## 글자 라벨
BODY_CHAR / NOTE_CHAR / INSERTED_CHAR / DELETED_MARK / ENVELOPE_CHAR / FIGURE_CHAR / MARGIN_CHAR

## text_source 값
| 값 | 의미 |
|---|---|
| transcript-aligned | NW 정렬 성공 (anchor 방식) |
| transcript-aligned-by-count | 글자 수 fallback 정렬 |
| figure-label-list | 도판 표기 목록에서 |
| panshim-header | 판심에서 |
| ocr | 테서랙트 원본 (정렬 실패) |
| manual | 사람이 직접 입력 |
| manual-reading | 확실하지 않은 사람 판독 |

## writing_direction (지도 표기)
vertical_ttb / vertical_spread / horizontal_rtl / horizontal_rtl_spread / arc_rtl / diagonal / diagonal_spread
