## 진단 항목
1. **쪽 유형**: textlayer 글자 수, 이미지 블록 크기, 해상도
2. **회전 감지**: 글자 성분 MinAreaRect 각도 히스토그램, 등각 투영 수렴점
3. **글자 배치**: 세로·수평·사선·호 배치 분류
4. **판독문 정렬 예상**: 예시 은행 anchor 예측, 글자 수 차이 경고
5. **잠재 오류**: 경위선 겹침, 붙은 상자, 빈 상자, 판독 불가 구간

## 4종 자료별 예상 진단

| 자료 | 주요 진단 | 자동 | 수동 |
|---|---|---|---|
| 사민필지 해설 쪽 | 텍스트레이어+영인 | textlayer+NW | 거의 없음 |
| 사민필지 지도 쪽 | 90° 회전+호 배치+경위선 | 회전 후 검출 | 호 배치 중심선 |
| 간이벽온방언해 | 벡터 윤곽선, OCR 필요 | 래스터 변환 | 판독문 OCR 검수 |
| 삼강행실도언해 | 96dpi, 삽화 혼재 | 삽화 탐지(낮음) | 영역 분리+값 입력 |
| 김씨부인 편지 | 봉투 수평+흘림체 | 봉투 검출+넓은행 | 행 상자+삽입 글자 |
| 김씨부인 곤전어필 | 복수이미지+면 번호 | 캡션 파싱+면 정렬 | 줄바꿈 위치 |
