소장자료총서 1 · 정조어필 한글편지첩 검수 라운드

제안기 버전별 상자 정확도

정답 상자와 IoU 0.5 이상 겹친 비율. 편지 3은 보정에 쓴 편지(학습셋), 편지 1·2·4는 제안을 만들 때 쓰지 않은 편지(검증)입니다.

검수 효율

막대: 제안을 고치지 않고 확정한 비율. 선: 100자당 검수 시간(분). 편지 3은 이력이 잘려 시간을 계산할 수 없습니다.

OCR 모델 성능 추이 (고정 평가셋)

HRCNet(ResNet 백본) 실행 결과를 '모델 실행'에 등록하면 평가셋 글자 정확도와 CER이 여기에 쌓입니다.

주의 신호

데이터·평가셋·검수에서 지금 확인할 것

편지별 결과

검수 한 번에 한 줄씩 쌓입니다. 제안 품질은 사람이 확정한 정답과 제안 원본을 비교한 값입니다.

정답 스냅샷

학습·평가에 쓰는 정답의 고정본입니다. 모델 실행은 반드시 스냅샷 id와 내용 해시로 기록해 계보를 남깁니다.

평가셋

학습셋 글자 빈도 (상위 25)

옛한글·자주 쓰는 글자에 쏠려 있는지 확인합니다.

실행 기록과 승격 판정

평가셋이 같고 챔피언보다 나빠지지 않은 실행만 '챔피언으로 지정'할 수 있습니다. 판정 기준: 글자 정확도 ≥ 챔피언, 옛한글 정확도 하락 2%p 이내, 평가셋 해시 일치.

아직 등록된 실행이 없습니다. HRCNet을 gold-r02로 평가하거나 미세조정한 뒤 결과 JSON을 등록하세요.

실행 결과 등록

GPU 환경에서 만든 결과 JSON 파일을 올립니다. 필수 항목을 확인한 뒤 저장합니다.
